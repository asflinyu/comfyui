# AI 分镜 · 生图 · 图生视频 · 数字人口播 一体控制台

> **适用平台**：AutoDL 共享 GPU 镜像  
> **技术底座**：ComfyUI + Wan 2.2 14B + Flux / Qwen + Qwen3-TTS  
> **文档版本**：v1.0 · 2026-09

---

## 产品简介

本镜像在 ComfyUI 之上封装了一套**网页控制台**，无需拖拽节点，即可使用：

- **Excel / 文案 → 分镜 → 出图 → 成片**（一键短剧流水线）
- **文生图 / 图生图**（Flux、Qwen、SDXL 等多工作流）
- **文生视频 T2V / 图生视频 I2V / 口播 S2V / Flux→视频 F2V**
- **数字人**：快速视频数字人、精品 Wan 14B 对口型

同时保留 **ComfyUI 原生界面（6006 端口）**，高级用户可自行加载、修改节点工作流。

---

## 两种使用方式（请先看懂）

| 方式 | 访问地址 | 适合谁 | 说明 |
|------|----------|--------|------|
| **① 控制台（推荐）** | AutoDL 公网 **6008** → 生成入口 | 普通用户、运营、艺术生 | 点按钮即可，不用学 ComfyUI |
| **② ComfyUI 工作流** | AutoDL 公网 **6006** | 进阶用户、调参、自定义 | 与官方 ComfyUI 相同，可 Load 工作流 JSON |

> **注意**：AutoDL 实例默认只映射 **6006** 和 **6008** 两个公网端口。  
> 控制台本机端口为 **6010**，通过 nginx 反代到 **6008** 对外暴露。  
> 本地调试可用：`http://127.0.0.1:6010/static/home.html`

## 5 分钟快速开始

### 第一步：确认 ComfyUI 已运行（6006）

SSH 或 Jupyter 终端执行：

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:6006/
```

返回 `200` 即正常。若失败：

```bash
screen -S comfy
cd /root/ComfyUI && python main.py --listen 0.0.0.0 --port 6006
# Ctrl+A 再 D 退出 screen
```

### 第二步：（可选）填写 AI 写分镜 Key

仅「原版分镜控制台 → AI 生成分镜」需要 LLM Key。快速版分镜读 Excel，**可不填**。

```bash
cd /root/ComfyUI/s2v_console_v2
cp -n .env.example .env
nano .env
```

填写 Moonshot（Kimi）或 DeepSeek 其一即可，详见 `.env.example`。

### 第三步：启动控制台

```bash
cd /root/ComfyUI/s2v_console_v2
screen -S s2v
./start.sh
```

成功时应看到：

```text
TTS 服务已就绪：http://127.0.0.1:6009
公网入口已就绪：nginx :6008 → 127.0.0.1:6010
Uvicorn running on http://0.0.0.0:6010
```

`Ctrl+A` → `D` 让进程在后台运行。

### 第四步：浏览器打开

1. 打开 AutoDL 控制台 → 该实例 → **自定义服务**
2. 点击 **6008** 的访问链接
3. 进入 **生成入口**（`/static/home.html`）

本机自检：

```bash
curl -s http://127.0.0.1:6010/api/health
```

`ok: true` 且 `comfy`、`tts` 为 `ok` 即可使用。

## 端口一览

| 端口 | 公网可访问 | 服务 | 用途 |
|------|------------|------|------|
| **6008** | ✅ | nginx → 控制台 | **买家主入口（生成入口）** |
| **6006** | ✅ | ComfyUI | 节点工作流、Load 官方/自定义 JSON |
| 6010 | ❌ 内部 | FastAPI 控制台 | 由 6008 反代，无需直接访问 |
| 6009 | ❌ 内部 | Qwen3-TTS 配音 | `start.sh` 自动拉起 |

## 功能导航（生成入口）

打开 **6008** 后，首页分为四大块：

### 1. 分镜成片（短剧 / 广告 / 毕业设计）

| 入口 | 路径 | 你给什么 | 得到什么 | 速度 |
|------|------|----------|----------|------|
| **快速版分镜** | `/fast` | Excel 镜头表 | 分镜图 + 720p I2V 成片 | ⚡ 快（无 LLM） |
| **分镜控制台 V2** | `/console` | 需求文案或 Excel | Kimi 写分镜 + 可选高清 | 较慢，选项多 |

**快速版推荐流程**：上传 Excel → 一键参考图 → 一键配音 → 生成视频 → 下载成片。

**原版流程**：优化需求 → AI 生成分镜 → 参考图 → 配音 → 跑全程 / 生成视频。

### 2. 图片生成

| 入口 | 说明 |
|------|------|
| Flux Dev | 高质量竖屏静帧 1280×2304 |
| Qwen Image | 中文提示词友好，Lightning 4 步 |
| SDXL / SD1.5 / SD3.5 | 传统文生图 |
| Flux Kontext / Qwen Edit | 图生图、改动作/换衣服 |
| SDXL I2I / 4x 放大 | 重绘或纯放大 |

### 3. 视频生成（四种）

| 模式 | 路径 | 输入 | 说明 |
|------|------|------|------|
| **T2V** | `/t2v` | 纯文字 | Wan 2.2 14B，无参考图 |
| **I2V** | `/i2v` | 底图 + 动作词 | **有图时最稳**，推荐 |
| **S2V** | `/s2v` | 人脸图 + 音频/台词 | 精品口播，约 15~25 分钟/镜 |
| **F2V** | `/f2v` | 出图词 + 动作词 | 先 Flux 出图再 I2V |

### 4. 数字人（两种）

| 模式 | 路径 | 特点 |
|------|------|------|
| **视频数字人** | `/talking-video` | 上传正脸视频作底片，秒~分钟级，嘴型驱动 |
| **精品 14B 口播** | `/s2v` | Wan S2V 重绘全身，质量最高，最慢 |

## 如何下载生成的视频 / 图片

生成完成后：

- **播放器**：结果区直接预览
- **下载链接**：`/comfy-output/文件名.mp4?download=true`
- **复制链接**：分镜控制台结果区有「复制链接」「下载成片」按钮

示例：

```text
https://你的实例.seetacloud.com:8443/comfy-output/s2v_console_shot_xxx.mp4?download=true
```

服务器磁盘位置（SSH 可取）：

```text
/root/ComfyUI/output/          # 视频成片（主目录）
/root/ComfyUI/s2v_console_v2/output/   # 备份副本
/root/ComfyUI/s2v_console_v2/uploads/  # 上传的底图、音频
```

## 方式②：ComfyUI 工作流（6006）

适合需要**自定义节点、Load 工作流、对比官方参数**的用户。

1. AutoDL → 自定义服务 → 打开 **6006**
2. 进入 ComfyUI 网页 UI
3. 可 `Load` 已有 JSON 工作流，或从 `custom_nodes` 里的 Wan / Flux 示例工作流改起

**与控制台的 relation**：

- 控制台内部也是向 **6006** 的 ComfyUI 提交任务
- 两边**不要同时**跑多个 14B 大任务，会抢 GPU
- 控制台出片在 `output/`，ComfyUI 默认输出也在 `/root/ComfyUI/output/`

## 画质 / 速度怎么选

| 场景 | 建议 |
|------|------|
| 试 prompt、毕业设计草稿 | 快速版分镜 + 720p + fast（4 步 LoRA） |
| 正式交付 | 原版控制台 + final_720 或 vertical_1080 + fast |
| 最高质量口播 | S2V 14B + 单镜 ≤3 秒 |
| 只要嘴动、要快 | 视频数字人 `/talking-video` |
| 艺术静帧 | Flux Dev 出图 → I2V 动起来 |

## 常见问题

**Q：公网 6008 打不开 / 502**  
A：控制台未启动。SSH 执行 `cd /root/ComfyUI/s2v_console_v2 && ./start.sh`，或 `screen -r s2v` 查看日志。

**Q：页面能开，生图/视频一直转圈**  
A：ComfyUI 6006 未运行或 GPU 占满。先 `curl http://127.0.0.1:6006/`。

**Q：配音失败 / 没声音**  
A：等 TTS 加载 1~2 分钟。查看 `/tmp/s2v_tts.log`。

**Q：AI 分镜报错**  
A：检查 `.env` 里 Moonshot / DeepSeek Key。或用**快速版分镜**（不依赖 LLM）。

**Q：SSH 断开程序停了**  
A：必须用 `screen` 启动，见上文「5 分钟快速开始」。

**Q：6060 端口？**  
A：本镜像 ComfyUI 为 **6006**，不是 6060。请使用 AutoDL 映射的 **6006**。

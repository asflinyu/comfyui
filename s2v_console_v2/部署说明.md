# S2V 分镜控制台 V2 · 部署说明

给拿到本镜像（或本仓库）的人：按下面做完，就能在 **公网浏览器** 打开控制台。

本应用跑在 AutoDL 上时，**请用自定义服务 6008** 访问。6006 是 ComfyUI 原页面，不是本控制台。

---

## 1. 机器要求

- GPU：建议 NVIDIA **24GB 及以上**（RTX 4090 / 5090）。Wan 2.2 14B fp8 加速路线按 24GB+ 设计。
- 系统：本镜像已装好 Python、ComfyUI、nginx、配音服务。
- AutoDL：实例开机后，系统盘 `/` 里的代码和模型会在。`/root/autodl-tmp` **不会**随镜像保存，不要把必要模型只放在数据盘。

---

## 2. AutoDL 上 5 分钟跑通（推荐）

### 2.1 开机

1. 用本镜像创建实例并开机。
2. 打开 **Jupyter / SSH 终端**。
3. 先确认 ComfyUI 在 6006（多数镜像开机已拉起）。终端执行：

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:6006/
```

返回 `200` 即可。若连不上，另开一个终端：

```bash
cd /root/ComfyUI
python main.py --listen 0.0.0.0 --port 6006
```

长期跑请用 `screen`（SSH 断开也不会停）：

```bash
screen -S comfy
cd /root/ComfyUI && python main.py --listen 0.0.0.0 --port 6006
# 按 Ctrl+A，再按 D 退出 screen，进程继续跑
```

### 2.2 填写大模型 Key（写分镜用）

```bash
cd /root/ComfyUI/s2v_console_v2
cp -n .env.example .env
nano .env
```

至少填一个（有 Moonshot 会优先用）：

```bash
MOONSHOT_API_KEY=sk-你的kimi密钥
MOONSHOT_BASE_URL=https://api.moonshot.cn/v1
MOONSHOT_MODEL=kimi-k2.7-code-highspeed

# 或者用 DeepSeek
DEEPSEEK_API_KEY=sk-你的deepseek密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

不填 Key 也能生图、I2V、S2V、配音；**原版分镜控制台里「AI 生成分镜」会不可用**。快速版分镜读 Excel，不依赖 LLM。

保存后不要把 `.env` 发到公开仓库。

### 2.3 启动控制台（这一步才会有公网入口）

```bash
cd /root/ComfyUI/s2v_console_v2
screen -S s2v
./start.sh
```

看到类似输出即成功：

```
TTS 服务已就绪：http://127.0.0.1:6009
公网入口已就绪：nginx :6008 → 127.0.0.1:6010
Uvicorn running on http://0.0.0.0:6010
```

再按 `Ctrl+A`、`D`，让它在后台跑。配音第一次加载大约 1～2 分钟，请等「TTS 服务已就绪」。

本机自检：

```bash
curl -s http://127.0.0.1:6010/api/health
```

`ok` 为 true，且 `comfy`、`tts` 为 `ok` 就可以开公网。

### 2.4 在 AutoDL 打开公网

AutoDL **默认只映射两个端口：6006 和 6008**。

1. 打开 AutoDL 控制台该实例页面。
2. 找到 **自定义服务** / **访问工具**。
3. 点 **6008** 对应的访问链接（一般是 `https://xxxx.seetacloud.com:8443`）。
4. 浏览器打开后应看到 **生成入口**（`/static/home.html`）。

| 你要点的端口 | 实际服务 | 用途 |
|---|---|---|
| **6008** | nginx → 控制台 6010 | **S2V 控制台 V2（用这个）** |
| 6006 | ComfyUI | 节点工作流后台，一般不用给终端用户 |

容器内部端口（AutoDL **不会**直接映射，不必改）：

| 内部端口 | 服务 |
|---|---|
| 6010 | 控制台 uvicorn |
| 6009 | Qwen3 TTS 配音 |

不要把配音绑到 6008，否则会把控制台公网入口挤掉。

### 2.5 入口里有什么

打开 6008 公网地址后：

- **快速版分镜**：Excel 文案 → 出图 + 720p 视频（推荐先试这条）
- **分镜控制台 V2**：可走 LLM 写分镜，可切高清（更慢）
- **生图 / I2V / F2V**
- **数字人两种**：视频数字人、精品 14B 口播（S2V）

## 3. 停机与重启

控制台占着 6010 时，再执行 `./start.sh` 会先释放该端口再拉起。

只停控制台：

```bash
python3 /root/ComfyUI/s2v_console_v2/kill_port.py 6010
```

配音日志：`/tmp/s2v_tts.log`  
nginx 配错：`/tmp/s2v_nginx_test.log`

回来继续看 screen：

```bash
screen -ls
screen -r s2v
```

## 4. 常见问题

**公网 6008 打不开 / 502**  
控制台没起来。先 `curl http://127.0.0.1:6010/api/health`，不行就重新 `./start.sh`。确认 6008 上是 nginx 而不是别的程序。

**页面能开，生图/视频一直转圈**  
ComfyUI 6006 没起来，或 GPU 被占满。看 Comfy 那个终端的报错。

**没有声音 / 配音失败**  
等 TTS 加载完。看 `/tmp/s2v_tts.log`。显存不够时先关掉其它占 GPU 的程序。

**AI 分镜失败**  
`.env` 里 Key 无效或没填。快速版分镜不需要 Key。

**SSH 一断程序就停**  
没用 screen。按第 2.1 / 2.3 节用 `screen` 再启动。说明见 [AutoDL 后台运行](https://www.autodl.com/docs/daemon/)。

**我改了 6010，公网却没变**  
公网永远走 **6008 → 6010**。改 `CONSOLE_PORT` 后必须同步改 `nginx-console.conf` 里的 `proxy_pass`。

## 5. 从源码自学（不用本镜像时）

目录在 ComfyUI 旁边：

```text
/root/ComfyUI/                  # 需要已能跑 Wan / Flux 的 ComfyUI
  s2v_console_v2/               # 本仓库
  ttsvoice/                     # 本地配音（Qwen3-TTS），start.sh 会自动拉起
  models/                       # 权重
  output/                       # 成片
```

依赖：本机 Python 能 `import` torch、fastapi、uvicorn、gradio_client、cv2 等（与当前 Comfy 环境共用即可）。

```bash
cd /path/to/ComfyUI/s2v_console_v2
cp -n .env.example .env
# 编辑 .env：COMFY_URL、TTS_URL、LLM Key
./start.sh
```

若没有 AutoDL，自己把 6010 做反向代理到 80/443，或把 `CONSOLE_PORT` 改成你要暴露的端口。没有 nginx 时，可直接访问 `http://服务器IP:6010/static/home.html`（需防火墙放行）。

## 6. 镜像作者保存前请自查（卖镜像的人看）

1. `.env` 里的 API Key **删掉**，只留 `.env.example`。
2. 必要模型放在 **系统盘**（`/` 或 `/root/ComfyUI`），不要只放 `/root/autodl-tmp`（保存镜像时带不走）。
3. 清掉 `uploads/`、`output/`、`data/` 里的私人成片和文案。
4. 确认开机后：Comfy 6006 能起来；买家按第 2.3 节执行 `./start.sh` 后，**6008 公网能打开生成入口**。
5. 把本文件路径告诉买家：`/root/ComfyUI/s2v_console_v2/部署说明.md`。
